## 文档约定

- 正文用中文，标识符用英文（`CLAUDE.md`）；**产品界面与运行时提示（观看页、HTTP/MCP 报错、MCP 工具描述、启动与诊断输出、脚本输出）一律英文**。代码注释仍用中文。
- **数字必须来自实际运行并注明环境**；没跑过的标「未验证」，不写推测。本文集里的实测环境见 [04 §已验证环境](04-依赖与环境.md)。
- 改了代码行为，同步改对应文档；改了 `crates/rig-proto`（AI 通道契约）必须同步 `PERCEPTION.md` 或 `EDGE_BROWSER.md` 并补测试。
- 新踩的坑先写进 `PITFALLS.md`，通用的再提炼进 [03](03-关键技术难点与解决.md)。
