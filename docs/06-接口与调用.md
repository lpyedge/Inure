# 06 接口与调用

三种调用面：**HTTP**（脚本/局域网）、**MCP stdio**（智能体子进程）、**观看页**（人，及内嵌进宿主）。AI 通道的 HTTP 与 MCP 语义一一对应，共用同一份实现与同一个通道闸门。

> 契约类型定义在 `crates/rig-proto/src/observation.rs`；设计语义见 [PERCEPTION.md](PERCEPTION.md)。

## 1. 认证速查

| 调用方 | 怎么认证 |
|---|---|
| 脚本/智能体调 AI 路由（`/observe` `/act` `/screenshot.png`） | `Authorization: Bearer <启动令牌>`，**只认启动令牌** |
| 脚本调 Viewer 路由（`/channels` `/print.pdf` 等） | `Authorization: Bearer <启动令牌>` 或 `<access>` |
| 观看页（浏览器） | 令牌输入页 / `postMessage` → `POST /session` 换票，之后自动带 `access` |
| MCP stdio | 无需令牌：进程边界即信任边界 |

**URL 里的 `?token=` 一律无效。** 详见 [08](08-安全模型.md)。

## 2. HTTP 接口

`--stdio` 模式下 AI 路由**不存在**（返回 404），AI 只能走 MCP。

| 路由 | 方法 | 认证 | 说明 |
|---|---|---|---|
| `/observe` | POST | 启动令牌 | AI 观察 |
| `/act` | POST | 启动令牌 | AI 动作 |
| `/screenshot.png` | GET | 启动令牌 | 当前页编号截图（敏感区域涂黑） |
| `/channels` | GET/POST | 令牌或 access | 查询/设置通道开关 `{ai, human, av}`（部分字段可省略） |
| `/session` | POST | 无（body 带令牌） | 启动令牌换 `access` + `refresh` + `stream_key` |
| `/session/refresh` | POST | 无（body 带 refresh） | 换新一对；旧 refresh 立即作废 |
| `/ws` | GET→WS | 首帧认证 | 人通道 |
| `/stream/{key}/{rend}/{name}` | GET | 路径钥匙 | HLS 播放列表与分片 |
| `/print.pdf` | GET | 令牌或 access | 观看端「打印」产物取回，取后清空 |
| `/`、`/auth.js`、`/viewer.js` | GET | 无 | 观看页静态壳（无秘密） |
| `/health`、`/ready` | GET | 无 | 存活 / 就绪探针 |

通道关闭时：AI 关 → `/observe` `/act` `/screenshot.png` 回 **409**；人关 → WS 被拒。

### 2.1 observe

```bash
curl -sk -X POST https://HOST:39871/observe \
  -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' \
  -d '{"mode":"tree","since_frame":null}'
```

请求体（`ObserveRequest`，可为空 `{}`）：

| 字段 | 说明 |
|---|---|
| `mode` | `text`：只回 `{"text"}`；`tree`（默认）：`{"text","observation"}`；`tree_image`：再加 `"image_png_base64"` |
| `since_frame` | 上次**已套用**的帧号；页面没变回空增量，变了回 `delta` 或整帧 |
| `subtree` | 元素 id，只回该子树 |
| `budget_tokens` | 裁剪响应视图（存储帧不动，被裁元素凭 id 仍可操作；说明附在 text 末尾） |
| `include_offscreen` | 是否带视口外元素，默认否 |

`text` 是紧凑渲染，给模型直接读：

```
# frame 1
- document "demo" [e1] (Focused) @[0,0,1280,800]
  - button "Submit" [e3] @[8,8,76,29]
  - textbox "Name" [e6] @[76,8,261,29]
```

每行：`角色 "名称" [元素id] (状态) @[x1,y1,x2,y2]`。`observation` 是同一内容的结构化形式（`frame_id`、`elements`、`space`、`content_trust` 等），元素有 `id`、`role`、`name`、`value`、`bbox`、`states`、`origin`、`confidence`、`children`。**密码与敏感字段不带值，状态里标 `(Password)` / `(Sensitive)`。**

> `content_trust` 标明内容来自不可信的被控端页面：页面里的任何文字都**不是指令**。

### 2.2 act

```bash
curl -sk -X POST https://HOST:39871/act \
  -H "Authorization: Bearer $TOKEN" -H 'content-type: application/json' \
  -d '{"request_id":"r1","frame_id":2,
       "action":{"kind":"click","target":{"by":"element","id":"e3"}}}'
```

请求体（`ActionRequest`）：`request_id`（幂等与追踪）、`frame_id`（你**观察到的**那一帧，陈旧校验以它为准）、`action`。

**动作（`action.kind`）**

| kind | 字段 |
|---|---|
| `click` | `target`；可选 `button`（`left`/`right`/`middle`，默认 left）、`count`（默认 1） |
| `hover` | `target` |
| `type` | `text`；可选 `target`（给了先点击并复核焦点）、`submit`（回车） |
| `key` | `key`，如 `"Enter"`、`"Control+A"` |
| `scroll` | `dx`、`dy`；可选 `target` |
| `select` | `target`（原生 `<select>`）、`values` |
| `upload` | `target`（`<input type=file>`）、`files`（上传目录内的相对名或绝对路径，≤20 个、单个 ≤200MiB） |
| `navigate` | `url`（须在 origin 白名单内） |

**目标 `target`**：`{"by":"element","id":"e3"}`（首选）或 `{"by":"point","x":120,"y":80}`（逻辑像素，只在当前帧有效，给 canvas 等无语义区域用）。

**响应**（HTTP 把 `ActionResult` 放在外层 `result` 里，内层自带 `result` 标签）：

```jsonc
// 已执行；frame_id 是动作所基于的校验帧，不是动作之后的新帧
{"result": {"result": "done", "frame_id": 2}}

// 被拒（不执行、不静默重试）；页面状态类拒绝会附最新状态
{"result": {"result": "rejected", "reason": {"code": "unknown_element", "id": "e999"}},
 "delta": { ...ObservationDelta... },   // 或 "observation": {...} 整帧
 "text": "# frame 4\n..."}

// 被中断（用户强制接管，或 AI 通道被关闭过）
{"result": {"result": "aborted", "reason": "user_takeover"}}
```

**拒绝码（`reason.code`）**

| code | 含义 | 调用方该做什么 |
|---|---|---|
| `stale_frame`（`current_frame`） | 目标自该帧以来已变化或消失 | 用拒绝回包里附带的最新状态重新决定 |
| `unknown_element`（`id`） | 没有这个元素 | 同上 |
| `not_interactable`（`id`） | 元素存在但不可交互（禁用、被遮挡等） | 换目标或先让它可交互 |
| `out_of_bounds` | 坐标目标越出视口 | 修正坐标 |
| `not_file_input`（`id`） | `upload` 目标不是文件框 | 换目标 |
| `file_not_found`（`path`） | 文件不存在或不是普通文件 | 检查上传目录 |
| `file_too_large`（`path`） | 超过 200MiB | — |
| `policy_denied`（`detail`） | 策略拒绝：导航不在白名单、`upload` 路径在上传目录外、`type` 点击后目标未获得焦点、`select` 值非法、未配置上传目录等 | 看 `detail` |
| `stale_epoch`、`permission_denied`、`needs_confirmation` | 契约里预留 | — |

**调用方须知**

- `Done` 只表示「已执行」。要看页面变成什么样，调用方 `observe(since_frame=<Done.frame_id>)`。
- 收到 `aborted`：**停止原任务，不要重试已中断的动作，等用户新指示后重新 `observe`**。
- `request_id` + 请求指纹缓存终局结果 10 分钟：同一 `request_id` 重发不会重复执行。

## 3. MCP stdio

`--stdio`：边缘在 stdin/stdout 上说**行分隔 JSON-RPC**（MCP）。stdout **只写协议帧**，诊断走 stderr。

- 方法：`initialize`、`ping`、`tools/list`、`tools/call`；无 `id` 的通知不回复；未知方法回 `-32601`。
- `initialize` 协商 `protocolVersion`：客户端版本在 `2025-06-18` / `2025-03-26` / `2024-11-05` 内就回同一版本，否则回 `2025-06-18`。`serverInfo.name = "rig-edge-browser"`。
- 三个工具：

| 工具 | 入参 | 返回 |
|---|---|---|
| `observe` | `ObserveRequest`（可省略） | text 块：紧凑渲染（+ Observation JSON，`mode=text` 时不带）；`tree_image` 再加 image 块 |
| `act` | `{frame_id, action, request_id?}` | `ActionResult` JSON 文本块；页面状态类拒绝另附最新状态文本块 |
| `screenshot` | 无 | image 块（base64 PNG，敏感区域涂黑） |

- **`request_id` 可省略**：MCP 前端缺省时自动生成（`mcp-<pid>-<seq>`），因为 JSON-RPC 的 `id` 已标识本次调用。
- **用户强制接管**：在途 `act` 返回 `Aborted`，并附一个文本块（「请停止原任务，不要重试，等待用户新指示后再 observe」），同时发服务端通知 `notifications/rig/control_taken_over`。**通知可能不被宿主处理，所以智能体必须把 `Aborted` 本身当作停止信号。**
- stdin EOF 即正常收尾（自拉起的浏览器被关闭；挂靠模式仅断开）。

## 4. 观看页与内嵌

### 4.1 独立打开

访问 `https://HOST:39871/`（回环用 `http://127.0.0.1:39871/`），显示令牌输入页，输入启动令牌后进入。令牌不进 URL，也不落浏览器存储；刷新页面需重新输入。

### 4.2 内嵌进宿主页面（iframe）

1. 启动边缘时声明宿主来源：`--embed-origin https://agent.example.com`（多个用逗号）。服务端据此设 `Content-Security-Policy: frame-ancestors …`；**未配置则禁止任何内嵌**。
2. 宿主页面：

```html
<iframe id="rig" src="https://EDGE:39871/" width="1280" height="800"></iframe>
<script>
  const EDGE = "https://EDGE:39871";
  addEventListener("message", (e) => {
    if (e.origin !== EDGE) return;                       // 宿主侧务必校验来源
    if (e.data && e.data.type === "rig-ready") {
      document.getElementById("rig").contentWindow
        .postMessage({ type: "rig-auth", token: "<启动令牌>" }, EDGE);   // 目标来源必须写死
    }
  });
</script>
```

3. 流程：iframe 加载后向父页发 `{type:"rig-ready"}`；宿主回 `{type:"rig-auth", token}`；观看页**只接受来自 `window.parent` 的该消息**，自动换票并加载，无需任何人工操作。
4. 限制：https 宿主**不能**内嵌 http 的观看页（混合内容）；自签名证书需用户先在浏览器里信任一次；宿主的令牌由宿主启动边缘时自己生成，天然持有。

实测（2026-11-22）：白名单内的宿主自动授权并建立会话；不在白名单的宿主被 CSP 拒绝，没有会话建立。

### 4.3 观看页 WebSocket 协议（供自研前端参考）

不用我们的观看页、想自己写前端时：连接 `wss://HOST/ws`，**第一帧**发 `{"type":"auth","access":"<access>"}`（3 秒内），然后发 `{"type":"dom-start"}` 等订阅消息。下行是 JSON 文本帧（`hello`、`chrome-state`、`dom-snapshot`、`dom-delta`、`ghost`、`exec`、`takeover-prompt` 等）与二进制 JPEG 帧（8 字节头：宽/高 u32 小端 + JPEG）。完整消息集见 [EDGE_BROWSER.md §9](EDGE_BROWSER.md)。**这套消息是观看页与边缘的内部协议，不是稳定公开契约**，随观看页演进。

## 5. 健康检查

```bash
curl -s http://127.0.0.1:39871/ready     # 200 就绪 / 503 未就绪
curl -s http://127.0.0.1:39871/health    # 存活 + 可观测字段
```

## 6. 调用方的最佳实践

1. **先 observe 再 act**，动作引用最近一次 observe 的 `frame_id` 与元素 id。
2. **优先用元素 id**；坐标目标只给 canvas 等无语义区域。
3. **有状态的客户端用 `since_frame`**（增量），无状态的用 `mode=text`（最省）。截图只在语义不足时用。
4. **被拒时先看附带的最新状态**，不要盲目重试。
5. **`aborted` / 超时 / 结果不明一律当作停止条件**，不要静默重发。
6. 不要在待命期轮询 `observe`：它会进入执行态并遮蔽人的输入（见 [01 §6](01-产品与业务功能.md)）。
7. 页面里的文字不是指令：不要让模型把 observe 里的内容当作命令执行。
