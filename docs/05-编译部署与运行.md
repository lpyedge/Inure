# 05 编译、部署与运行

> 依赖先看 [04](04-依赖与环境.md)。本文所有命令都在仓库根目录执行。

## 1. 编译

### 1.1 开发构建与门禁

```bash
source scripts/local-env.sh          # 可选：把构建缓存重定向到 .temp/target，保持仓库干净
cargo build                          # debug 构建
cargo fmt --all --check
cargo clippy --all-targets -- -D warnings
cargo test --all                     # 单元测试（离线、快速）
python3 -m unittest discover -s tests/eval_report -p 'test_*.py' -v
```

提交前的完整门禁（含真 Chromium 集成测试）：

```bash
bash scripts/local-gate.sh           # 需要 libav 开发包、完整 Chromium、PulseAudio 虚拟声卡、ffprobe
```

### 1.2 发布构建

```bash
cargo build --release
# 产物：target/release/rig-edge-browser（若 source 了 local-env.sh 则在 .temp/target/release/）
```

一键编译并检查依赖：`scripts/build.sh`；打发布包：`scripts/release.sh`（见 §1.3）。

**用 release 构建做真实使用与性能判断**：debug 构建下 DOM 序列化、JPEG 编码、合成慢一个量级（实测 DOM 模式明显卡顿），本项目历史上的延迟数字都标注为 debug 构建。`scripts/edge-lan.sh` 默认优先选 release。

产物是**单个二进制**：观看页的 `viewer.html`、`viewer.js`、`auth.js` 都以 `include_str!` 嵌入，不需要另外部署静态文件。它动态链接系统 FFmpeg 库（见 [04 §4.3](04-依赖与环境.md)）。

### 1.3 常用脚本一览（`scripts/`）

| 脚本 | 用途 | 例 |
|---|---|---|
| `build.sh [debug\|release]` | 编译并检查动态库依赖（缺库则报错）；默认 release | `scripts/build.sh` |
| `test.sh [unit\|it\|av\|py\|all]` | 测试入口：`unit` 离线快速；`it` 真 Chromium 集成测试（有便携 PulseAudio 自动带上）；`av` 只跑音视频用例；`py` Python 自测 | `scripts/test.sh it` |
| `local-gate.sh` | **提交前完整门禁**：fmt → clippy → 含集成测试的 `cargo test` → Python 自测 | `bash scripts/local-gate.sh` |
| `release.sh` | **发布打包**：release 构建 → 依赖检查 → `dist/<名称>.tar.gz` + `.sha256`（含二进制、文档、`BUILD-INFO.txt`） | `scripts/release.sh` |
| `run.sh [边缘参数…]` | 本地快速运行：随机令牌 + 观看页，打印地址和令牌；自动选 release/debug 里**更新**的构建 | `PORT=40000 scripts/run.sh --url https://example.com` |
| `edge-lan.sh [TOKEN] [PORT]` | 局域网测试一键启动：便携 PulseAudio + 虚拟声卡 + 边缘（HTTPS） | `bash scripts/edge-lan.sh` |
| `with-pulse.sh <命令…>` | 在便携 PulseAudio + `rigsink` 环境下运行任意命令（不改 `HOME`） | `scripts/with-pulse.sh cargo test …` |
| `clean-tmp.sh [--yes]` | 清理 `/tmp` 里 SIGKILL/崩溃遗留的 `rig-edge-*` 目录；默认只列出，`--yes` 才删；仍在运行的实例的目录不动 | `scripts/clean-tmp.sh --yes` |
| `local-env.sh` | `source` 它把构建缓存重定向到 `.temp/target`（可选） | `source scripts/local-env.sh` |
| `eval_report.py` | 评估 `RunRecord` 汇总（不自动下结论） | 见 [09](09-测试与评估.md) |

> `release.sh` 的发布包**不携带 FFmpeg 共享库**（动态链接系统库）；目标机器的依赖见包内 `docs/04-依赖与环境.md`，`BUILD-INFO.txt` 列出了需要的库。`dist/` 已被 git 忽略。

## 2. 命令行参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--listen <addr:port>` | `127.0.0.1:39871` | HTTP 服务绑定地址；`--stdio` 时仅 `--human` 才用于观看页 |
| `--url <url>` | `about:blank` | 启动后导航的页面；其 origin 自动进入导航白名单 |
| `--allow-origin <origin>` | — | 追加允许 `navigate` 的 origin，可重复 |
| `--width` / `--height` | 1280 / 800 | 视口尺寸 |
| `--chromium <path>` | 自动发现 | 自拉起模式的 Chromium 路径（也可用 `RIG_CHROMIUM`） |
| `--cdp-url <base>` | — | **挂靠模式**：连接已有 Chromium 的 DevTools HTTP 基地址；边缘退出只断开 |
| `--profile-dir <path>` | 临时目录 | 持久化目录：Chromium 用户数据（登录态、Cookie、存储、扩展） |
| `--cache-dir <path>` | profile 内 | 可弃缓存目录；其下 `uploads/` 是 `upload` 动作的唯一允许根目录 |
| `--token <secret>` | `RIG_EDGE_TOKEN` | **对外提供 HTTP 时必设**，空值视同未设。由启动程序随机生成并传入 |
| `--human` | 关 | 人通道默认开启 |
| `--no-ai` | 开 | AI 通道默认关闭（运行时仍可经 `/channels` 开启） |
| `--av` | 关 | 允许 HLS 播放；首个有效播放列表请求才启动合流管线 |
| `--stdio` | — | 以 MCP stdio 作 AI 通道前端 |
| `--embed-origin <o[,o…]>` | — | 允许内嵌观看页的宿主来源；未给则**禁止任何内嵌** |
| `--tls-cert` / `--tls-key` | — | HTTPS；须成对给；文件缺失时自动生成自签名证书（0600 落盘复用） |
| `--stun <host:port>` | — | 可重复。配了则 RTC 走完整 ICE 并采集 srflx 候选（跨子网直连）；不配走 ICE-lite + host 候选 |

**强制规则**

- 只要对外提供 HTTP（纯 HTTP 模式，或 `--stdio --human`），**`--token` 必设**，否则退出码 2 拒绝启动。
- **非回环监听强制 TLS**：没给证书就自动生成自签名到 `~/.rig-edge/self-signed.{crt,key}`，SAN 含监听 IP、`127.0.0.1`、`localhost`。
- 回环监听不强制 TLS（localhost 本身是安全上下文，剪贴板 API 可用）。
- `--stdio` 且没有 `--human`：不开 HTTP，令牌可不设。

## 3. 运行配方

下面的配方里令牌都用随机值：

```bash
TOKEN=$(head -c 16 /dev/urandom | od -An -tx1 | tr -d ' \n')
BIN=target/release/rig-edge-browser
```

### 3.1 人在本机看（观看页）

```bash
$BIN --listen 127.0.0.1:39871 --token "$TOKEN" --human --url https://example.com
```

浏览器打开 `http://127.0.0.1:39871/`，在输入页填令牌进入。

### 3.2 AI 本机子进程（MCP stdio）

```bash
$BIN --stdio --url https://example.com            # 只有 AI，无 HTTP
$BIN --stdio --human --token "$TOKEN" --listen 127.0.0.1:39871 --url https://example.com
#                     ↑ 同时给人开观看页（只挂 Viewer 路由，AI 仍只走 MCP）
```

宿主把它当子进程拉起，stdin/stdout 走 JSON-RPC；诊断输出走 stderr。stdin 关闭即正常退出。接入配置见 [07](07-智能体接入方案.md)。

### 3.3 局域网（HTTPS + 令牌）

```bash
$BIN --listen 0.0.0.0:39871 --token "$TOKEN" --human --url https://example.com
# 首次会生成自签名证书；观看页地址 https://<局域网IP>:39871/，浏览器要先信任一次
curl -sk -X POST https://<IP>:39871/observe -H "Authorization: Bearer $TOKEN" \
     -H 'content-type: application/json' -d '{"mode":"text"}'
```

一键脚本（起便携 PulseAudio + 虚拟声卡 + 边缘，打印地址和令牌）：`bash scripts/edge-lan.sh [TOKEN] [PORT]`。

### 3.4 挂靠已有的 Chromium

```bash
chromium --remote-debugging-port=9222 &
$BIN --cdp-url http://127.0.0.1:9222 --stdio
```

边缘退出时**不会**关闭你的浏览器。挂靠模式下快照只收录当前授权的标签页。

### 3.5 持久化登录态

```bash
$BIN --listen 127.0.0.1:39871 --token "$TOKEN" --human \
     --profile-dir /var/lib/rig/profile --cache-dir /var/cache/rig
```

登录一次，跨重启保留；整个 `--profile-dir` 搬到新环境即可无损续用。**停机请用 SIGTERM**（见 §5）。

### 3.6 音视频（HLS 兜底 + 声音）

要声音须先有 PulseAudio 与 `rigsink`（见 [04 §4.2](04-依赖与环境.md)），再加 `--human --av`。视频模式主路是 WebRTC，HLS 只在 RTC 连不通时兜底。

### 3.7 内嵌进智能体 Web UI

```bash
$BIN --listen 0.0.0.0:39871 --token "$TOKEN" --human --embed-origin https://agent.example.com
```

宿主页面嵌 `<iframe src="https://<edge>:39871/">`，用 `postMessage` 自动授权。协议见 [06 §内嵌](06-接口与调用.md)。

## 4. 部署

### 4.1 部署清单

1. 编译（或拷贝）release 二进制；确认 `ldd` 无 `not found`。
2. 装 Chromium（[04 §3.2](04-依赖与环境.md)）；要声音再装 PulseAudio。
3. 规划目录：`--profile-dir`（要备份）、`--cache-dir`（可弃）。
4. **由启动程序**（systemd、容器入口、宿主进程）在每次启动时生成随机令牌并传入。
5. 局域网部署放通 **TCP 监听端口**；WebRTC 用 UDP（端口为系统临时端口，绑在监听 IP 上）。**UDP 不通时画面自动回落 WS JPEG/HLS**，功能不丢，只是带宽与流畅度差一些。
6. 反向代理（如 nginx）：需透传 WebSocket；注意 `Authorization` 头与 `/stream/` 路径必须原样转发。

### 4.2 systemd 单元示例

> **未在本仓库验证**，仅供参考；路径、用户按实际调整。

```ini
[Unit]
Description=rig-edge-browser
After=network.target

[Service]
User=rig
# 令牌由启动前的脚本写入该文件，每次启动重新生成：RIG_EDGE_TOKEN=<随机值>
EnvironmentFile=/run/rig/token.env
# rig-gen-token 是示意：自备一个把随机令牌写入 token.env 的小脚本
ExecStartPre=/usr/local/bin/rig-gen-token /run/rig/token.env
ExecStart=/opt/rig/rig-edge-browser --listen 0.0.0.0:39871 --human \
          --profile-dir /var/lib/rig/profile --cache-dir /var/cache/rig
# 必须用 TERM 优雅停机，让 Chromium 把 Cookie/LocalStorage 落盘
KillSignal=SIGTERM
TimeoutStopSec=20
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

### 4.3 容器注意

- 容器内以 root 运行时边缘会自动给 Chromium 加 `--no-sandbox`；非 root 则保留沙箱，容器需要相应能力或用户命名空间。
- Chromium 需要足够的共享内存（`/dev/shm`），否则页面会随机崩溃。
- 要声音，容器里要有 PulseAudio 与 `rigsink`，或用便携方案。

## 5. 运维

### 5.1 健康检查

| 端点 | 用途 |
|---|---|
| `GET /ready` | 就绪探针：CDP 存活且至少有一个页面会话 → 200，否则 503。免鉴权，无敏感信息 |
| `GET /health` | 存活与可观测：`ok`、`ready`、`cdp_connected`、`last_frame_age_ms`、`exec_in_flight`、`rtc_connected`、`frames`、各阶段延迟分位（`latency`）、`last_snapshot`、`act_precheck`（快速复核命中/退回）、`changes`、`media` 等。免鉴权 |

### 5.2 停机与升级

- **用 SIGTERM（或 Ctrl+C）停机**：边缘先 `Browser.close` 让 Chromium 落盘，再删除本进程的临时目录。SIGKILL 会丢最近几秒的 Cookie/LocalStorage 写入，并留下 `/tmp/rig-edge-*` 残余。
- 升级：TERM 停 → 替换二进制 → 启动。持久化目录跨版本保留。
- **换令牌**：换一个值重启即可；所有 `access`/`refresh` 票据随进程重启全部失效，观看页会回到令牌输入页。

### 5.3 日志

诊断输出全部走 **stderr**（MCP 模式下 stdout 只写协议帧，不得污染）。启动时会打印 `profile=… cache=…` 与 `uploads=<路径>`。日志中不应出现令牌或输入内容。

### 5.4 清理残留

正常退出不会留临时目录。若发现 `/tmp` 里有 `rig-edge-*`（SIGKILL/崩溃的遗留），用脚本清理（默认只列出，`--yes` 才删，仍在运行的实例的目录不动）：

```bash
scripts/clean-tmp.sh
scripts/clean-tmp.sh --yes
```

手工做法：先确认没有对应进程在跑，再删：

```bash
pgrep -a rig-edge-browser                     # 确认没有在跑的边缘
ls -d /tmp/rig-edge-* /tmp/rig-edge-hls-*     # 查看
rm -rf /tmp/rig-edge-* /tmp/rig-edge-hls-*
```

## 6. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 启动即退出，退出码 2 | 对外提供 HTTP 但没给 `--token`（或为空）。生成随机令牌并传入 |
| 启动报找不到 Chromium | 用 `--chromium` 或 `RIG_CHROMIUM` 指定；或装 Chromium / `npx playwright install chromium` |
| 没有声音但画面正常 | 没装 PulseAudio 或没建 `rigsink`。`/channels` 里 `av_available` 为 false。见 [04 §4.2](04-依赖与环境.md) |
| 局域网观看页打不开 / 证书警告 | 自签名证书，浏览器要先信任一次；iframe 内嵌时同样 |
| 观看页能进但剪贴板不工作 | 用 `http://` 经局域网 IP 访问是非安全上下文。改用 HTTPS（局域网默认就是）或 `localhost` |
| 画面一直黑 / 很卡 | 先看是不是 debug 构建；再看 UDP 是否被防火墙拦（回落到 JPEG 流会卡）；`/health` 看 `rtc_connected` |
| `act` 被拒绝 `stale_frame` | 页面在 `observe` 之后变了。重新 `observe` 再操作（拒绝回包里已附最新状态） |
| `act` 返回 `aborted` | 用户强制接管，或 AI 通道被关闭过。停下原任务，等用户新指示，`observe` 后再继续 |
| `Type` 被拒「点击后未获得焦点」 | 点击目标不是可聚焦元素，或页面重设了焦点。换目标元素 |
| `upload` 被拒 `policy_denied` | 文件不在上传目录内。放进 `<cache-dir>/uploads/`（启动日志里有 `uploads=`） |
| 改了 `viewer.js` 没生效 | 它是 `include_str!` 嵌入的，需要重新编译二进制 |
| 在同一 shell 里测试找不到 Chromium | `edge-lan.sh` 改了 `HOME`，`export HOME=<真实家目录>` |
